# Añadir entrada de catálogo

Una entrada de catálogo describe un libro u otra fuente de aprendizaje. Puedes incluir un enlace de origen o definir la entrada por tu cuenta.

## Registrar una fuente

1. Abre **Catálogo** y selecciona la opción para **registrar una fuente**.
2. Indica un **ID de catálogo** único y un **nombre**. Ambos son obligatorios y admiten hasta 100 caracteres.
3. Completa **Materia**, **Tema** y **Autor**; son campos obligatorios.
4. Añade una descripción opcional.
5. Ajusta la casilla **Activo** según corresponda.
6. Envía el formulario con la acción de creación.

La creación requiere permisos adecuados. Si no está disponible, revisa el inicio de sesión y tu rol, o utiliza los datos de ejemplo locales para experimentar en tu dispositivo.

## Entrada con enlace

Introduce la dirección de referencia en el campo opcional **Fuente**. Utiliza la URL proporcionada por el propietario y comprueba que tengas acceso. El enlace es información de referencia: añadirlo no importa automáticamente un catálogo maestro ni concede acceso al contenido de otra persona.

Para clonar un catálogo maestro completo desde una fuente compartida, utiliza **Clonar catálogo maestro**. Esta acción está disponible cuando tu catálogo está vacío.

## Entrada definida por el usuario

Deja **Fuente** vacía y describe tu material con los campos obligatorios y la descripción. Puedes organizar un tema de estudio personal sin una URL externa.

## Revisar y editar

Localiza la entrada mediante la búsqueda o los filtros del catálogo. Ábrela para consultar su contenido o utiliza **Editar** para actualizar sus datos. El ID no se puede modificar al editar una entrada existente.

Comprueba el estado de sincronización después de guardar. En el modo de datos de ejemplo locales, los cambios permanecen en este dispositivo y no se envían al servidor.
