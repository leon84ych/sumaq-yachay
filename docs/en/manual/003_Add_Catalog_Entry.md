# Add Catalog Entry

A catalog entry describes a book or another learning source. You can include a source link or define the entry yourself.

## Register a source

1. Open **Catalog** and select **Register Source**.
2. Provide a unique **Catalog ID** and a **Catalog Name**. Both are required and allow up to 100 characters.
3. Fill in **Subject**, **Topic**, and **Author**; these fields are required.
4. Add an optional description.
5. Set the **Active** checkbox as appropriate.
6. Submit the form using the create action.

The create action requires the appropriate permissions. If it is unavailable, check your sign-in status and role, or use Local Sample Data to experiment locally.

## Entry with a link

Put the reference address in the optional **Source** field. Use the source URL provided by its owner, and check that you have access. A source link is reference information; adding it does not automatically import a master catalog or grant access to another person's content.

To clone an entire master catalog from a shared source, use **Clone Master Catalog** instead. This action is available when your catalog is empty.

## User-defined entry

Leave **Source** empty and describe your own material using the required fields and description. You can organize a personal study subject without an external reference URL.

## Review and edit

Find the entry using search or the catalog filters. Open it to inspect its content, or use **Edit** to update its details. The ID cannot be changed while editing an existing entry.

Check the synchronization status after saving. In Local Sample Data mode, changes remain on this device and are not sent to the server.
